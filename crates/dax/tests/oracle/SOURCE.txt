Files in this folder are ours: model.bim is our synthetic model, corpus.json and the probe
list of signatures.json are generated by BIcraft (xtask/src/oracles/dax_corpus_data.rs and
signatures.rs, write_signature_probes_on_request).

verdicts.json and signatures.json hold verdicts recorded with the maintainers' development
oracles (outside this repository) against Microsoft's Analysis Services engine, used as a black
box. Only our own data is stored: accepted or refused, BIcraft's error class, and argument
counts. No engine message text and no Microsoft file is stored here.

signatures.json (M11.40):
  Engine: Analysis Services 17.0.93.23 of Power BI Desktop 2.159.1231.0 (Store), locale 1033.
  Recorded: 2026-11-23.
  Method: each probe is deployed as a measure of Sales on model.bim (query-only functions run as
  an EVALUATE query); its state is read from the model's measure schema rowset and, when
  accepted, the measure is evaluated at the grand total. Minimum and maximum argument counts are
  the numbers the engine states in its argument-count errors for calls with 0 and 40 arguments.
  See docs/dax-oracle.md "Signature corpus".
