# BIcraft roadmap

Goal: an open-source, pure-Rust tool, with a CLI and an MCP server, that reads, writes, validates and compiles Power BI files (PBIX, PBIT, PBIP, PBIR) and validates DAX on Windows and Linux.

Status legend: ✅ done · 🔄 in progress · ⏳ next · ⬜ later. Commits use the milestone id (`M1.2: …`).

## What is left (2026-11-25)

Every item of M0–M12 is ✅, and every milestone is marked done (2026-11-25). What is
left is tracked as open gaps in [docs/gaps.md](docs/gaps.md) (79 on 2026-11-25: no P0, 10 P1, 40 P2,
29 P3), above all:

- **Refresh** (G50, P1 since 2026-11-25): Desktop opens refreshed and new PBIX files up to
  10 M rows a table; the RLS and Excel checks are left, and rows are held in memory per table.
- **Connectors** (G68, G69, G46): SQL Server, Web, OData and SharePoint tested only against test
  servers; no OAuth sign-in, no privacy firewall; the Power Query editor's remaining tools (G67).
- **Engine** (G10, G30, G31, G32): DirectQuery not executed, a few DAX forms, speed at 100 M rows
  and beyond RAM, aggregation leftovers.
- **Reader** (G51): drill icons in the HTML viewer, cross-report drillthrough, the Desktop oracle.
- **Distribution** (G8): the first release, v0.1.0, is prepared (`cargo xtask dist`, run by the
  release workflow per OS); nothing published yet, and the release workflow has never run.
- **Server and sign-in**: `bicraft-cli serve`'s OIDC is tested only against a local test provider
  with generated keys, never against a real identity provider (the Entra ID, Google, Keycloak and
  Okta setups in docs/auth.md are documentation, not tested); no token introspection, no logout,
  viewer logins lost on restart.
- **Kubernetes**: the image, the Helm charts and the workspace controller are tested only in a
  throwaway local kind cluster (WSL, October 2026), never on a managed cluster (AKS, EKS, GKE)
  or under real load; one controller replica (no leader election), polling rather than watches.
  Treat it as a preview, not a production deployment.
- **Platforms**: Windows and Linux (x86-64) only. macOS is neither built nor tested; no arm64
  build locally.
- **Checks**: the gate (`cargo xtask ci`) runs on the maintainers' Windows machine and in WSL
  Ubuntu; GitHub Actions are off, so no public CI result exists yet.
- **Power BI service**: BIcraft's files and visuals are checked in Power BI Desktop only;
  publishing to the Power BI service and Report Server is not tested.
- **BIcraft visuals** (G105, G109–G118): each still to be seen in Desktop for its latest features,
  high contrast, and the drawing leftovers listed per visual.

The progress log is in [docs/history/roadmap-log.md](docs/history/roadmap-log.md); the item tables
of the finished milestones M0–M10 and the storage engine plan are in
[docs/history/roadmap-done.md](docs/history/roadmap-done.md).
